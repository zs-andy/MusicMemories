# Contributing to Music Memories

Thank you for your interest in contributing to **Music Memories**!

## Great Places to Contribute

- Integrate official MusicKit / Spotify metadata and 30-second song previews.
- Upgrade on-device subject detection models or add Vision foreground lifting.
- Polish timeline animations, dark mode contrast, and VoiceOver accessibility.

## Workflow

1. Fork the repository and create a branch (`feat/...` or `fix/...`).
2. Open `Package.swift` in Xcode 16+ or Swift Playgrounds 4.5+ and verify it builds for iOS/iPadOS 17+.
3. Keep changes focused and avoid committing `.DS_Store`, API keys, model weights, or user-specific IDE state (`xcuserdata/`).
4. Open a pull request describing what changed and how you verified it.
